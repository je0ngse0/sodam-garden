# 소담정원 · Sodam Garden

서두르지 않아도 괜찮아요. 씨앗을 심고, 꽃을 돌보고, 고양이와 쉬어가는 작은 브라우저 게임입니다.

## 실행

Node.js 20 이상에서 다음 명령을 실행한 뒤 http://127.0.0.1:4173 에 접속하세요. 패키지 설치는 필요하지 않습니다.

```sh
npm start
```

포트를 변경하려면 `PORT=4180 npm start`를 사용하세요. `index.html`을 직접 열기보다는 로컬 서버로 실행해 주세요.

## 정원 가꾸기

- 꽃을 선택한 뒤 빈 꽃밭을 눌러 심습니다. 씨앗은 무제한입니다.
- 물 주기 도구로 한 번 물을 주면 데이지 30초, 튤립 40초, 라벤더 50초 후에 꽃이 핍니다.
- 꽃 종류마다 크림이, 모모, 밤이가 찾아옵니다. 발견한 세 마리가 동시에 머물며 산책하고 낮잠을 잡니다. 정원의 고양이나 도감 버튼으로 각각 쓰다듬을 수 있습니다.
- 연못이나 물고기 밥 주기 버튼을 누르면 물고기 세 마리가 모여듭니다. 한 번 먹는 동안 10초 기다리면 다시 줄 수 있고, 밥을 주지 않아도 불이익은 없습니다.
- 옮기기 도구로 꽃을 선택하고 빈칸을 누르면 성장 상태를 유지한 채 이동합니다.
- 도구 단축키: `1` 씨앗, `2` 물, `3` 옮기기, `4` 꽃다발, `5` 산책. 모든 버튼은 키보드로도 조작할 수 있습니다.
- 소리 버튼으로 잔잔한 합성 음을 켭니다. 기본값은 무음입니다.

정원은 브라우저의 localStorage에 자동 저장됩니다. 창을 닫아도 물을 준 시각을 기준으로 성장합니다. 로그인과 서버 저장은 없으며, 다른 기기와 동기화되지 않습니다. 브라우저 데이터를 삭제하면 정원도 지워집니다. 저장이 차단된 환경에서는 화면에 안내합니다.

## 개발과 검증

```sh
npm test
```

- 순수 JavaScript ES Modules, HTML, CSS, Canvas 2D, Web Audio
- 본 게임은 외부 런타임 의존성 없음 (별도 3D 미리보기만 로컬 Three.js 사용)
- 정원과 고양이는 코드로 그린 자체 벡터 그림
- Google Fonts의 Gowun Batang / Noto Sans KR 사용. 오프라인에서는 시스템 글꼴로 대체
- 반응형 레이아웃, 키보드 조작, 접근 가능한 꽃밭 버튼, reduced-motion 지원
- 테스트: 성장, 물 중복 사용, 옮기기, 오프라인 성장, 고양이 해금, 손상된 저장 복원

`index.html`과 `src/`를 정적 호스팅에 올리면 실행됩니다. 제공하는 로컬 서버는 개발 미리보기 용도입니다.

## 첫 버전 범위

24칸 정원, 꽃 3종, 함께 산책하고 낮잠 자는 고양이 3마리, 물고기 3마리가 사는 연못과 밥 주기, 자동 저장, 꽃 옮기기와 잔잔한 소리까지 구현했습니다. 작은 화면에서는 정원을 좌우로 스크롤할 수 있습니다. 날씨는 맑은 날 고정이며 계절 변화, 상점, 온라인 공유는 포함하지 않습니다.

## 저장 데이터 호환

기존 `sodam-garden-v1` 저장 키를 유지하며 데이터 형식은 version 3으로 확장했습니다. version 1과 2의 정원을 모두 불러올 수 있습니다. 이전 4×3 꽃밭을 6×4 꽃밭의 같은 행과 열에 옮겨 꽃 종류, 물 준 시각, 고양이 도감과 쓰다듬기 횟수를 보존합니다. 연못의 밥 준 횟수와 마지막 식사 시각도 저장합니다.

## 정원사와 꽃다발

- 잔디와 길을 클릭하면 성인 여성 정원사 소담이 걸어갑니다. 산책 도구에서는 꽃밭이나 연못을 눌러도 가까운 통행 가능한 곳으로 갑니다.
- 벤치 또는 `벤치에서 쉬기` 버튼을 누르면 꽃밭과 연못을 피해 걸어가 앉습니다. 잔디를 누르면 다시 일어납니다. 산책 모드에서 정원에 초점을 둔 뒤 방향키로도 이동할 수 있습니다.
- `꽃다발` 도구로 다 핀 꽃 3~9칸을 선택하세요. 다시 누르면 선택이 해제되며, 묶기 전까지 꽃은 그대로 남습니다.
- `꽃다발 묶기`를 누르면 선택한 칸만 비워지고 보관함에 꽃 종류와 제작 날짜를 저장합니다. 빈칸에는 즉시 다시 심을 수 있습니다.
- 정원사는 가장 최근에 만든 꽃다발을 들고 다닙니다. 고양이 도감은 꽃을 수확해도 유지됩니다.
- 정원사 위치와 앉은 상태, 꽃다발은 자동 저장됩니다. 이전 버전에는 이 항목을 기본값으로 추가합니다.
- 그래픽은 Canvas 기반 2D입니다. 잔디·흙의 질감과 명암, 성인 체형의 캐릭터, 관절이 움직이는 네 발 고양이를 코드로 그립니다. 사진이나 3D 모델을 사용하는 방식은 아닙니다.


## 3D 미리보기 · 크림이의 작은 오후

`npm start` 후 http://127.0.0.1:4173/preview-3d.html 에서 별도로 체험할 수 있습니다.

- 작은 잔디 디오라마와 코드로 만든 크림이 한 마리. Three.js / WebGL 2 기반의 실제 3D입니다.
- 드래그 / 한 손가락으로 카메라 회전, 휠 / 두 손가락으로 확대·축소. 화면 버튼으로도 조절할 수 있습니다.
- 정원 영역에 키보드 초점을 두고 방향키로 회전, `+` / `-`로 확대·축소합니다.
- 쉬기, 원형 경로 산책, 고양이 클릭 또는 버튼으로 쓰다듬기, 노을빛 전환, 움직임 정지와 시점 초기화를 지원합니다.
- 운영체제의 동작 줄이기 설정에서는 처음부터 애니메이션을 정지합니다. 버튼으로 직접 재생할 수 있습니다.
- 본 게임의 모듈을 불러오지 않으며 localStorage, sessionStorage, IndexedDB를 사용하지 않습니다. 정원 저장 기록을 읽거나 바꾸지 않고, 체험 상태는 새로고침하면 초기화됩니다.
- Three.js **0.186.1**의 필요한 파일과 MIT 라이선스를 `vendor/three/`에 포함했습니다. 설치나 CDN 연결이 필요하지 않습니다. 모델과 잔디 질감은 직접 생성하며 외부 이미지·모델·폰트를 내려받지 않습니다.
- 3D 미리보기를 정적 호스팅에 포함하려면 `preview-3d.html`, `src/preview3d/`, `vendor/three/`도 함께 배포하세요.
- 주요 파일: `cat.js`(메시와 관절), `garden.js`(잔디와 주변 소품), `motion.js`(보행과 경로), `main.js`(장면과 조작).
- 현재는 그래픽 시제품입니다. 기존 꽃밭·꽃다발·정원사 기능이 3D로 전환된 것은 아닙니다. WebGL 2가 필요하며 기기 성능에 따라 재생 속도가 달라질 수 있습니다.
